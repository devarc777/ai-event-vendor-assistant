# AI Event & Vendor Assistant

AI-assisted event creation, vendor suggestions chat, and adaptive vendor onboarding Q&A for marketplace workflows.

## Included
- AI parse / create event from natural language
- Event title suggestions
- AI vendor suggestions chat
- AI vendor onboarding Q&A
- Frontend chat + AI training onboarding page

## Setup
1. Copy `.env.example` to `.env`
2. `npm install`
3. `npx prisma generate`
4. `npm run start:dev`

Extracted from production marketplace work under NDA. Branding removed from package metadata.
